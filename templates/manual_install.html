Machine installation manual

Gaming Smart – Machine installation manual

For technicians and floor staff. Every machine is installed, photographed and registered once. After that, wins, losses and payouts are linked to it automatically and the photos stay on file for audit.

Before you start

  1. An admin adds the machine under Machines with its code, location and model. The code must be the one printed on the cabinet label.
  2. Bring a phone with a working camera and a data connection, the machine's serial plate details, and the printed code label.
  3. Sign in with your own account so the installation is recorded against your name.

Step by step

  1. Open Machines, find the machine and tap Install.
  2. Power up the machine and play a test round. Tick powered up and test-played only when it worked.
  3. Fix the machine code label to the cabinet where it can be read from the floor.
  4. Take the five photos below. The app reads the plate, label and meter, fills in the serial number and opening meters, and flags anything that does not match this machine.
  5. Check every filled-in value (green border) against the machine itself. The photo reading is a helper, never the authority.
  6. Tick the checklist, add notes, and tap Save installation. You can save part-way and return later.

Photo standard

  • Hold the phone flat and square to what you are photographing, so the text is not skewed.
  • Fill the frame with the plate, label or screen. No glare, no fingers, no reflections.
  • Show the whole cabinet for the front photo, and enough of the surroundings for the position photo that someone could find the machine from it.
  • Retake any photo the app cannot read. Typed values are still accepted, but the record is marked as not machine-read.

What the system checks

Serial numberMust be unique. A serial already registered to another machine is refused.
Code labelThe code read from the label photo must be this machine's code.
Serial plateThe serial read from the plate photo must match what was typed.
Opening metersCoin in and coin out must match the meter photo. They are saved as the first meter reading and used later to check captured takings.
CompletenessThe machine is verified only when all five photos, the serial number and the whole checklist are done and nothing was flagged. Otherwise it shows incomplete or needs review.

After installation

  • Staff capture wins and losses against the machine on the Wins / Losses page. Payouts of R {{ '{:,.0f}'.format(lo) }} or more go on Large payouts.
  • Take a meter photo from the Machines page regularly. The BI board compares meter movement with captured takings and shows the variance.
  • If a machine is moved, repaired or its plate is replaced, open Install again and retake the affected photos. Earlier photos stay in the audit trail.
  • Switch a machine off on the Machines page when it leaves the floor. Its history is kept.

Planned: direct machine integration

This manual covers manual photo capture, which works on any machine today with no changes to it. Direct integration is a later option and is not built yet. It would let a machine report its meters and payouts to the app automatically. Typical routes are a slot-accounting protocol interface on the machine, or a data feed from the venue's existing accounting system. The serial number, model and opening meters captured here are what such an integration would use to identify each machine and to check its first readings.
